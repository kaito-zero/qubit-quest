H를 두 번 걸고 1,000번 뽑으면 어떻게 될까요?

    상태 [a, b][1.000, 0.000]
    0이 나올 확률
    100.0%
    1이 나올 확률
    0.0%

    게이트 걸기

    0이 나온 횟수
    0
    1이 나온 횟수
    0

    DAILY 1 클리어

    • 큐비트는 측정하면 0 또는 1이 나오는 뽑기 기계다.
    • 상태 [a, b]의 각 숫자를 제곱하면 확률이고, 합은 항상 1이다.
    • 측정 전에는 결과를 알 수 없고, 확률만 정해져 있다.
    • 게이트는 [a, b]를 정해진 규칙으로 바꾼다.
    • 숫자는 음수가 될 수 있어서 서로 지워진다. 이것이 간섭이고, 동전 던지기와 다른 점이다.

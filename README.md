# Qubit Quest

하루에 한 판, 직접 눌러 보며 배우는 양자컴퓨팅.

**플레이:** https://kaito-zero.github.io/qubit-quest/

- Daily 1: 큐비트와 측정
- Daily 2: 복소수, 크기와 위상
- Daily 3: 상태 벡터와 디랙 표기법
- Daily 4: 측정과 보른 규칙
- Daily 5: 행렬과 유니터리
- Daily 6: 단일 큐비트 게이트 정리
- Daily 7: 1주 차 복습
- Daily 8: 텐서곱과 두 큐비트
- Daily 9: 2큐비트 게이트 CNOT, CZ, SWAP
- Daily 10~30: 준비 중. 공부한 내용이 하루에 한 판씩 추가됩니다.

앞의 판을 클리어하면 다음 판이 열립니다.
